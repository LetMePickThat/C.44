Before writing code for a step of [[radar-roadmap]], first restate why the step exists (raison d'être), what goes in
(inputs) and what comes out (outputs), then code once the user agrees. Comes after the variable questions of
[[ask-for-every-variable]].

**Why:** user request 2026-10-20 at step 0.2 ("Rappeler avant d'aborder le code la raison d'être, les entrants, les sortants").
**How to apply:** short French summary (purpose / inputs / outputs / what it does not do), then wait for the OK.
